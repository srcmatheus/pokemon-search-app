# pokemon-search-app

---

Este projeto consiste em uma aplicação web desenvolvida com HTML, CSS e JavaScript puro, que consome dados da PokéAPI.

A interface permite ao usuário buscar Pokémon específicos ou gerar um Pokémon aleatório, exibindo informações relevantes de forma dinâmica.

Foram aplicados conceitos como:

- consumo de API REST via fetch

- manipulação do DOM

- tratamento de eventos

- organização visual com CSS

O projeto tem como objetivo aprender e praticar integração com APIs externas e desenvolvimento front-end.
